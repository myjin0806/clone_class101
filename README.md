## ⭐️프로젝트 설명
> 이 사이트는 Class101의 클론 프로젝트로, 다양한 온라인 클래스를 소개하고 할인 정보를 제공합니다.<br> 주요 기능은 강의 카테고리별로 필터링 가능하고, 할인 혜택과 추천 강의도 쉽게 확인할 수 있습니다.<br> 사용자는 수많은 강의를 한 곳에서 검색하고, 각 강의에 대한 상세 정보와 할인 혜택을 확인할 수 있습니다.<br> 또한, 사용자 친화적인 디자인을 통해 편리한 탐색 경험을 제공합니다.
